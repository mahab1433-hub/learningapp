# 🌟 WonderSparks - Primary Education Learning App (Grades 1 to 5)

WonderSparks is a modern, child-friendly web learning platform designed specifically for primary school students in **Grade 1 through Grade 5**. It offers interactive, bite-sized courses across three foundational subjects: **English**, **Mathematics**, and **Social Science**.

---

## 🚀 Key Features

### 1. Progressive Multi-Grade Curriculum (Grades 1 to 5)
- **Grade 1 (Ages 5-6):** Alphabet, Phonics (CVC words), Counting with Pictures, Shapes & Patterns, 5 Senses & Myself.
- **Grade 2 (Ages 6-7):** Nouns & Adjectives, 3-Digit Place Value (Hundreds, Tens, Ones), Community Helpers & Safety.
- **Grade 3 (Ages 7-8):** Verb Tenses (Past, Present, Future), Fraction Visualizer (Halves & Quarters), Maps & Directions (Compass & India).
- **Grade 4 (Ages 8-9):** Prepositions of Place/Time, Factors, Multiples & Prime Numbers, Physical Geography of India (Himalayas, Northern Plains, Thar Desert).
- **Grade 5 (Ages 9-10):** Active & Passive Voice, Percentage Trio (Fractions, Decimals, %), Indian Constitution & Democratic Rights.

### 2. Complete Lesson Experience: Subject → Course → Unit → Lesson
Every single lesson includes:
1. **Simple Explanation:** Clear concepts with mascots and a **"Listen 🔊"** Read-Aloud button powered by the browser's Web Speech API.
2. **Visual Examples:** Illustrated cards, tags, and real-world representations.
3. **Interactive Activity:** Hands-on puzzle widgets (CVC word builder, apple counters, pattern solver, pair matcher, fraction slicer, etc.).
4. **Quick Practice:** Instant-check practice questions with immediate feedback.
5. **Challenge Mini Quiz:** 5–10 varied questions (Multiple Choice, True/False, Fill-in-the-blank).
6. **Quiz Scorecard & Detailed Review:** Star ratings (⭐⭐⭐), XP, confetti celebration, review of correct/incorrect answers with explanations, **Retry Quiz**, and **Next Lesson** flow.

### 3. Progress Tracking & Gamification
- **Daily Learning Goal:** Target tracker (e.g. 2 lessons/day).
- **Streak Tracker:** Daily learning streak with animated flame icon.
- **Star Coins & XP:** Earn coins and XP by finishing lessons and scoring well on quizzes.
- **Trophy Cabinet:** Unlockable achievement badges (*First Step*, *Math Wizard*, *Streak Fire*, *Quiz Ace*, *Star Collector*, etc.).
- **Learning Analytics:** Subject mastery progress bars and quiz attempt logs.

### 4. Child-Friendly Design & Audio Delight
- **Typography:** Google Fonts *Fredoka* and *Quicksand* for optimal readability and playful feel.
- **Interactive Sound Effects:** Built-in procedural Web Audio API synthesizer (no external audio files needed; includes success arpeggios, error bumps, button clicks, star twinkles, and celebratory fanfares) with mute toggle.
- **Avatar Selector:** 6 cheerful learning buddy avatars (Felix Fox, Oliver Owl, Leo Lion, Pip Panda, Astro Sam, Dara Dolphin).
- **Mobile Bottom Navigation:** Responsive bottom tab bar (Home | Courses | Progress | Profile).
- **LocalStorage Sync:** Learner progress, streak, and scores are automatically saved.

## 🛠️ Running Locally

The app is built with **Vite + React** and custom **Vanilla CSS**.

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start the local development server
npm run dev

# 3. Open in your browser
http://localhost:5173/
```

To build for production:
```bash
npm run build
```
